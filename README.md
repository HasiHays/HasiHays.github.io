# Hasi Hays - Professional Portfolio

A modern, responsive portfolio website for Dr. Hasi Hays, showcasing research in Computational Systems Biology, Machine Learning, and Artificial Intelligence.

## Live Site

**URL:** [https://hasihays.github.io](https://hasihays.github.io)

## Features

- Modern dark theme with colorful gradients
- Fully responsive design (mobile-first)
- Smooth scroll animations
- Interactive typing effect
- Animated skill bars
- Publication filter
- Floating navigation with blur effect
- Profile picture with animated ring

## Tech Stack

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts (Inter, Space Grotesk)

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/HasiHays/hasihays.github.io.git
   ```

2. Navigate to the directory:
   ```bash
   cd hasihays.github.io
   ```

3. Open `index.html` in your browser or use a local server.

## Deployment

This is a GitHub Pages site. Push to the `main` branch and it will automatically deploy to:
- **https://hasihays.github.io**

## Customization

### Update Profile Picture
Replace `assets/profile.jpg` with your own image.

### Update Publications
Edit the publications section in `index.html` to add or remove papers.

### Change Colors
Modify the CSS variables in `css/style.css`:
```css
:root {
    --primary: #6C63FF;
    --secondary: #FF6584;
    --accent: #00D2AF;
    /* ... */
}
```

## Sections

1. **Hero** - Name, title, profile picture, social links
2. **About** - Research focus, experience, tech stack
3. **Education** - Academic timeline
4. **Research** - Current positions, skills, GitHub repos
5. **Publications** - Filterable publication list
